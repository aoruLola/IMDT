## 标记说明

- `[x]` 完整看并练：官方大纲直接覆盖，或 2023—2026 真题稳定出现。
- `[△]` 快速看：本轮需要过课，掌握定义、结构、基本操作和典型题，不做复杂证明或大量编程题。
- `[ ]` 暂不看：主要是 C++ 语法或计算机科班深度实现，不影响 843 主线。

## 结论先看

总体策略：数据结构目录基本全部过一遍，但只把高频主线练到能手算、写伪代码和分析复杂度；低频章节快速看定义、结构图、基本操作和适用场景。

最后快速过：C++ 语法、KMP 改进、红黑树、B 树/B+树、十字链表、邻接多重表、关键路径的复杂推导。它们不是完全不看，而是不在第一轮投入同等时间。

### 零、预备知识

- [△] C 语言预备知识：变量、数组、指针、结构体、函数、递归、动态内存、链表结点写法。
- [ ] C++ 预备知识：类、模板、STL、继承、多态等不作为 843 网课主线；只需能看懂资料中的少量 C++ 伪代码。

验收：能读懂 `struct`、指针、数组下标、链表插入/删除和递归伪代码即可，不要在 C/C++ 语法上消耗整套网课时间。

### 第一章 绪论

- [x] 时间复杂度：基本操作、最好/最坏/平均情况、数量级和大 O。
- [x] 空间复杂度：辅助空间、原地算法、递归栈空间。
- [x] 数据结构基本概念：数据、数据元素、数据项、逻辑结构、存储结构、数据类型、抽象数据类型。
- [x] 算法基本概念：定义、特性、正确性、健壮性、可读性、可实现性、效率；算法与程序的区别。
- [△] 补充：递归、迭代、分治、贪心、动态规划全部快速过一遍，只掌握基本思想和复杂度，不进入竞赛级算法。

验收：能判断一个算法的时间/空间复杂度，并解释顺序表、链表、树、图分别属于什么逻辑结构。

### 第二章 线性表

- [x] 线性表的定义和基本操作：初始化、求长、按位查找、按值查找、插入、删除。
- [x] 线性表的实现。
- [x] 顺序存储：地址计算、随机访问、插入删除代价、扩容和复杂度。
- [x] 链式存储：单链表结点、头指针/头结点、查找、插入、删除、逆置、合并。
- [x] 线性表的应用：有序表合并、按条件拆分、去重、逆置等典型算法。
- [x] 双链表：前驱/后继指针、插入、删除、边界处理。
- [x] 循环链表：判空、尾指针、插入删除、约瑟夫环基础。
- [△] 静态链表：数组模拟指针、基本操作和适用场景；不必深挖。
- [x] 顺序表和链表比较：访问、插入、删除、存储、适用场景和复杂度。
- [x] 单链表、循环链表和双循环链表的比较：判空、首尾操作、指针维护。

验收：闭卷写出单链表插入、删除、逆置、合并；能解释为什么“按序号访问”适合顺序表、“频繁插入删除”适合链表。

#### 栈和队列

- [x] 栈和队列的基本概念：后进先出、先进先出、栈顶、队头、队尾、基本操作。
- [x] 栈和队列的顺序存储结构。
- [x] 顺序栈：入栈、出栈、判空、判满、溢出。
- [x] 顺序队列：入队、出队、队空、队满和假溢出。
- [x] 循环队列：取模、队空/队满判定、有效元素个数。
- [△] 双端队列：两端进出、受限双端队列；看概念、结构和简单序列判断即可。
- [x] 栈和队列的链式存储结构：链栈、链队列、头尾指针、判空和边界。

#### 数组和特殊矩阵

- [x] 数组的存储和地址计算：按行优先、按列优先、多维数组下标。
- [x] 特殊矩阵的压缩存储：对称矩阵、三角矩阵、对角矩阵。
- [x] 稀疏矩阵：三元组表、非零元素、转置和压缩存储思想。

#### 应用与串

- [x] 栈、队列和数组的应用：括号匹配、表达式求值、递归、迷宫、层序遍历、缓冲。
- [△] 串：串的定义、长度、子串、串的存储和基本操作；快速看基础概念。
- [△] 简单模式匹配算法：暴力匹配过程和复杂度；看懂并会手算即可。
- [△] KMP 算法：掌握 next 数组、匹配过程和复杂度；不必刷大量变式。
- [△] 改进 KMP 算法：掌握与普通 KMP 的区别；放在本章最后快速看。

验收：能手算循环队列、栈序列、括号匹配、稀疏矩阵/对称矩阵压缩下标；这些比 KMP 更优先。

#### 二叉树主线

- [x] 树的基本概念：结点、根、叶、度、层次、高度、路径、森林。
- [x] 二叉树：定义、左右子树、满二叉树、完全二叉树。
- [x] 二叉树的定义及其主要特征：结点数关系、度为 0/1/2 的结点关系、高度和层数。
- [x] 二叉树的存储结构：顺序存储、二叉链表、三叉链表基础。
- [x] 二叉树的遍历：先序、中序、后序、层序；递归和非递归思想。
- [x] 由遍历序列构造二叉树：先序+中序、中序+后序的还原。
- [x] 线索二叉树的基本概念和构造：前驱、后继、线索化和遍历。

#### 树、森林和应用

- [△] 树的存储结构：双亲表示、孩子表示、孩子兄弟表示；掌握差异和基本操作。
- [△] 森林与二叉树的转换：孩子兄弟表示法和转换规则。
- [△] 树和森林的遍历：先根/后根、对应二叉树遍历关系。
- [x] 树与二叉树的应用：层次、高度、结点数、路径和遍历综合题。
- [△] 哈夫曼树和哈夫曼编码：构造、带权路径长度、编码；看典型题即可。
- [x] 并查集及其应用：父指针、查找、合并；至少掌握 Kruskal 中的用途。
- [ ] 补充：超出教材主线的树形结构证明和复杂递归题，暂时跳过。

验收：能根据遍历序列画树；能完成二叉树结点数/高度判断、线索化基础、哈夫曼树基础和并查集连通性判断。

#### 基础与存储

- [x] 图的基本概念：顶点、边、度、入度、出度、路径、回路、连通、权值、有向/无向图。
- [x] 图的存储及基本操作：邻接矩阵、邻接表的建立、查找和遍历准备。
- [x] 邻接矩阵法：适用图类型、空间复杂度、边/度查询。
- [x] 邻接表法：结点结构、出边遍历、空间复杂度。
- [x] 邻接矩阵和邻接表的比较：稠密/稀疏图、存储空间、访问效率和适用操作。
- [△] 十字链表：掌握它是有向图存储结构、结点字段和基本适用场景；不做复杂实现题。
- [△] 邻接多重表：掌握它是无向图存储结构、结点字段和基本适用场景；不做复杂实现题。
- [△] 总结：整理存储结构选择题和复杂度对比表。

#### 遍历与连通性

- [x] 图的遍历：访问标记、遍历森林、重复访问处理。
- [x] 深度优先搜索 DFS：递归/栈、遍历序列、连通分量和复杂度。
- [x] 广度优先搜索 BFS：队列、层次、遍历序列和复杂度。
- [x] 图的遍历与连通性：连通分量、可达性、生成树基础。

#### 图的基本应用

- [x] 最小生成树 MST：生成树定义、Prim、Kruskal、边数、权值和并查集。
- [△] 最短路径：Dijkstra 的基本思想、松弛、单源最短路径和适用条件；会手算小规模例子。
- [△] 弗洛伊德算法：多源最短路径、状态转移和矩阵更新；会手算小规模例子即可。
- [△] 拓扑排序：入度法、DFS 法、AOV 网、环检测。
- [△] 关键路径：掌握 AOE 网、事件/活动、入度出度和最长路径的基本计算；复杂推导后置。
- [△] 小结：把 DFS/BFS、MST、最短路径、拓扑排序的输入、输出、数据结构和复杂度做成对比表。

验收：能手算 DFS/BFS、判断连通性、完成 Prim/Kruskal；能解释 Dijkstra、Floyd、拓扑排序各自解决什么问题。

### 第六章 查找

- [x] 顺序查找法：查找过程、成功/失败、平均查找长度和搜索概率。
- [△] 分块查找法：索引表、块内顺序查找、适用条件和复杂度。
- [x] 折半查找法：有序条件、查找过程、判定树、最大比较次数和复杂度。
- [x] 树型查找：树形查找总体思想和查找效率比较。
- [x] 二叉搜索树 BST：定义、查找、插入、删除和平均/最坏复杂度。
- [△] 平衡二叉树 AVL：平衡因子、失衡、LL/RR/LR/RL 调整；掌握概念和旋转。
- [△] 红黑树：掌握性质、颜色约束和基本查找思想；不投入完整插入删除调整。
- [△] B 树及其基本操作、B+ 树的基本概念：掌握阶、结点结构、查找和应用差异；不深入复杂删除。
- [x] 散列哈希表：哈希函数、冲突、线性探测、开放定址、装填因子、查找成功/失败。

验收：能手算折半查找比较次数、顺序查找平均长度、BST 插入删除、哈希线性探测和装填因子。

#### 基础与内部排序

- [x] 排序的基本概念：关键字、稳定性、原地性、内部/外部排序、最好/最坏/平均复杂度。
- [x] 插入排序：基本思想、过程和适用场景。
- [x] 直接插入排序：每趟结果、稳定性、复杂度。
- [△] 折半插入排序：比较次数与移动次数，理解与直接插入的差异。
- [△] 希尔排序：分组插入、增量序列和复杂度结论；不深挖复杂证明。
- [x] 交换排序：基本思想和比较对象。
- [x] 冒泡排序：每趟结果、提前结束、稳定性和复杂度。
- [x] 快速排序：分区、递归、每趟结果、稳定性、最好/最坏/平均复杂度和空间复杂度。
- [x] 选择排序：基本思想和比较对象。
- [x] 简单选择排序：过程、稳定性和复杂度。
- [x] 堆排序：大根堆/小根堆、建堆、调整、每趟结果、稳定性和复杂度。
- [x] 归并排序：二路归并、递归、链式结构归并、稳定性和复杂度。
- [△] 基数排序：多关键字、桶/队列、稳定性；掌握思想和基本过程。

#### 外部排序与应用

- [x] 外部排序：大规模数据、归并段、多路归并；重点理解为什么 50TB 数据不能直接内存排序。
- [x] 排序算法的分析与应用：稳定性、空间、时间、数据规模、数据是否有序、内存限制下的选择。
- [x] 堆的应用——优先队列：插入、取最大/最小、删除堆顶；2025 相关范围，按主线掌握。

验收：至少能手算快速排序、堆排序、归并排序各一轮；能从稳定性、复杂度和数据规模选择排序方法。

## 看课顺序

1. 绪论 → 线性表 → 栈队列数组。
2. 二叉树 → 图的存储与 DFS/BFS → MST。
3. 查找：顺序/折半/BST/散列。
4. 排序：插入/冒泡/快速/堆/归并 → 外部排序与优先队列。
5. 最后补 AVL、哈夫曼、最短路径、拓扑排序、串基础。

## 不要用“听完”作为完成标准

- 线性表：闭卷写单链表插入、删除、合并。
- 栈队列：手算循环队列和栈序列。
- 树：根据两种遍历序列还原二叉树。
- 图：手算 DFS/BFS、Prim 或 Kruskal。
- 查找：手算折半查找和哈希线性探测。
- 排序：手算快速排序、堆排序、归并排序，并写稳定性/复杂度。

## 依据

- 2027 官方 843 大纲：A（三）明确列出“集合与算法的基本概念、数据结构及其运算、查找与排序”。
- 2023—2026 843 回忆版矩阵：数据结构与算法四年均有较大分值；线性表、栈队列、树、图、查找、排序和散列均有真题记录。
