## 3.1 词汇与词法

- [ ] `P0` 5500 左右考研核心词：词义、词性、熟词僻义、近义词/反义词、形近词。
- [ ] `P0` 派生：前缀、后缀、词根；名词、动词、形容词、副词之间的转换。
- [ ] `P0` 固定搭配：动词搭配、介词搭配、形容词搭配、名词搭配、常见短语动词。
- [ ] `P0` 一词多义和语境义；学术、社会、科技、经济、教育、环境、文化类高频词。
- [ ] `P1` 熟悉常见拉丁/希腊词根和高频学术词族，能够在阅读中根据上下文猜词。

网课关键词：`考研英语一核心词汇`、`熟词僻义`、`词根词缀`、`考研英语高频搭配`。

### 3.2 语法与长难句

- [ ] `P0` 句子成分：主语、谓语、宾语、表语、定语、状语、补语、同位语。
- [ ] `P0` 基本句型：五大基本句型；并列句；复合句；主干识别。
- [ ] `P0` 名词、代词、冠词、数词、介词、连词、形容词、副词的基本用法。
- [ ] `P0` 时态：一般现在/过去/将来、进行时、完成时、完成进行时；时态呼应。
- [ ] `P0` 语态：主动与被动；被动结构的识别和翻译；特殊被动句。
- [ ] `P0` 非谓语：不定式、动名词、现在分词、过去分词；逻辑主语、时态和语态。
- [ ] `P0` 三大从句：名词性从句、定语从句、状语从句；连接词和省略。
- [ ] `P0` 虚拟语气：条件句、愿望、建议、命令、必要性、事实相反表达。
- [ ] `P0` 主谓一致；倒装；强调；省略；替代；插入语；同位语；分裂结构。
- [ ] `P0` 比较结构、否定结构、因果/转折/让步/条件/目的逻辑。
- [ ] `P0` 长难句：多层从句、插入成分、并列平行、抽象名词化、后置定语、指代关系。
- [ ] `P1` 标点辅助断句：逗号、分号、冒号、破折号、括号在阅读中的逻辑作用。

验收：每篇真题长难句能划出主干、从句边界、逻辑词和指代对象，并写出自然中文。

### 3.3 完形填空

- [ ] `P0` 语篇主旨和段落逻辑；首句、转折句、结尾句定位。
- [ ] `P0` 词义辨析：同义、近义、形近、语域和感情色彩。
- [ ] `P0` 固定搭配和习惯表达；动词、介词、名词、形容词搭配。
- [ ] `P0` 语法线索：时态、语态、非谓语、主谓一致、从句连接词。
- [ ] `P0` 逻辑线索：转折、因果、递进、并列、让步、条件、解释、举例。
- [ ] `P1` 复盘每个错误属于词汇、搭配、语法、逻辑、语篇或选项干扰。

网课关键词：`考研英语完形逻辑`、`完形填空选项辨析`、`完形错题归因`。

### 3.4 阅读理解 A

- [ ] `P0` 文章结构：总分、因果、对比、问题—解决、现象—解释、观点—论据。
- [ ] `P0` 段落功能：主题句、例证、转折、让步、结论、定义、数据、引用。
- [ ] `P0` 主旨题：全文主旨、标题、作者中心观点；避免以局部细节代替主旨。
- [ ] `P0` 细节题：定位、同义替换、事实核对、范围和程度判断。
- [ ] `P0` 推理题：隐含结论、因果链、作者未明说但可推出的信息。
- [ ] `P0` 观点态度题：作者态度、语气、评价词；区分作者观点和他人观点。
- [ ] `P0` 例证题：例子证明的观点、所在段落作用、与主旨的关系。
- [ ] `P0` 词义题：上下文定义、同位解释、因果、对比、替换验证。
- [ ] `P0` 指代题：代词、指示词、同义复现、语法一致和语义一致。
- [ ] `P0` 复杂选项：绝对化、偷换概念、扩大/缩小范围、因果倒置、无中生有。
- [ ] `P1` 社会科学、自然科学、商业管理、教育文化、科技伦理类文章的常用论证套路。

验收：每篇真题完成“段落主旨—题目定位—正确选项证据—错误选项陷阱”四栏复盘。

### 3.5 新题型

- [ ] `P0` 七选五：段落主旨、代词指代、逻辑连接、复现词、句式衔接、首尾呼应。
- [ ] `P0` 排序题：时间顺序、因果链、代词回指、主题句和段落承接。
- [ ] `P0` 小标题：段落核心信息、并列结构、概括性表达。
- [ ] `P1` 选项多余信息的排除；先确定锚点，再处理剩余位置。

网课关键词：`英语一新题型七选五`、`考研英语排序题`、`小标题题`。

### 3.6 翻译

- [ ] `P0` 先找主干：主语、谓语、宾语；再拆从句和非谓语。
- [ ] `P0` 定语从句、同位语从句、名词性从句、状语从句的准确转换。
- [ ] `P0` 被动、倒装、强调、插入语、否定、比较、抽象名词化的翻译。
- [ ] `P0` 代词指代、逻辑关系、时态语气、术语和上下文语义。
- [ ] `P0` 英译汉重组：拆分长句、补出省略、调整语序、避免逐词硬译。
- [ ] `P1` 译文标准：忠实、通顺、准确；检查漏译、错译、逻辑断裂和中文不自然。

### 3.7 写作

- [ ] `P0` 应用文格式：称呼、正文、结尾、署名、日期；书信、通知、邀请、道歉、感谢、申请、建议信、告示等。
- [ ] `P0` 应用文功能表达：提出请求、解释原因、提供建议、表达感谢/道歉、确认安排。
- [ ] `P0` 大作文图表：柱状图、折线图、饼图、表格、动态图；趋势、比较、峰值、比例、原因和意义。
- [ ] `P0` 大作文图画/漫画：描述画面、揭示寓意、解释原因、提出评价或建议。
- [ ] `P0` 三段式组织：现象/描述—分析—结论/建议；段落主题句与衔接。
- [ ] `P0` 高频功能词：因果、转折、递进、举例、让步、总结、比较、趋势和程度。
- [ ] `P1` 句式升级：定语从句、非谓语、被动、名词化、同义替换；避免模板痕迹和语法错误。
- [ ] `P1` 小作文 100 词左右、大作文 160—200 词左右的时间和字数控制，以当年大纲为准。

验收：每周完成至少 1 篇阅读精析；9 月后每周小作文/大作文各 1 次，必须批改和二次重写。
