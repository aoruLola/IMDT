# 算法与线性结构：让步骤可执行

## 843-algorithm | 算法、复杂度与递归 | 算法；伪代码；时间复杂度；空间复杂度；递归

### 目标
用输入输出、终止条件和不变式解释一个算法。

### 问题
找出一摞书中编号最大的书，为什么“多试几次”不算完整算法？

### 讲解
算法是解决一类问题的有限、明确、可执行步骤，须说明输入、输出和适用条件。伪代码表达逻辑，不依赖具体编译器。本课程过程示例除明确列出的C文件外均为伪代码。O(n)描述规模增长时工作量的上界阶，不是精确秒数。常见阶为常数、对数、线性、n log n、平方。额外空间只计辅助存储还是含输入，应先说明。

递归是函数调用自身，必须有基本情形和趋近它的度量。每层调用保留局部状态，深度会占栈空间，递归不会天然更快。

### 推导
求最大值：若数组空则返回“无最大值”；否则max←a[0]，从i=1到n−1比较并更新。循环不变式：处理完下标i后，max是前i+1项最大值。递归阶乘：fact(0)=1；n>0时fact(n)=n×fact(n−1)，n必须非负且结果未溢出。

### 例题1
[3,1,4,4]依次比较，max为3→3→4→4，3次比较，时间O(n)、额外空间O(1)。重复最大值不影响值结果，但求“全部位置”要另存索引。

### 例题2
fact(3)展开3×fact(2)→3×2×fact(1)→3×2×1×fact(0)，再回收得6。时间O(n)，调用栈O(n)；迭代累乘额外空间可为O(1)。

### 练习1
O(n²)是否表示每个输入都恰好执行n²步？
提示：阶忽略常数与低阶项。
解析：不是，也可能是3n²+2n等上界，还须说明最好/平均/最坏情形。

### 练习2
双循环i=1到n，内层j=1到i，执行次数？
提示：求1+2+…+n。
解析：n(n+1)/2，量级O(n²)。不能因为内层上界变化就说O(n)。

### 练习3
递归f(n)=f(n)为什么无法正常结束？
提示：度量是否减少？
解析：没有更小子问题，也没有能到达的终止分支，会反复调用直至资源耗尽。

### 回顾
算法要同时回答：算什么、为何对、何时停、要多少资源。

### 补充
先按图示和正文用纸笔追踪，再阅读以下伪代码。箭头←为赋值，“若”为条件，“当”为循环；不是可直接编译的C。

```伪代码
max(a,n):
  若 n=0：返回“无最大值”
  best ← a[0]
  对 i=1 到 n−1：
    若 a[i]>best：best ← a[i]
  返回 best
```
