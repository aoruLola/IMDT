# 算法与线性结构：让步骤可执行

## 843-strings-arrays | 串、数组与稀疏矩阵 | 串；模式匹配；KMP直觉；多维数组；稀疏矩阵

### 目标
看懂字符串匹配过程和节省存储的条件。

### 问题
一个百万行矩阵只有千个非零数，仍要把所有零存下来吗？

### 讲解
串是字符序列，子串连续，子序列可跳过。朴素模式匹配在每个起点逐字符比较，最坏O(nm)。KMP利用模式自身前后缀信息，失配时保留已知匹配关系，时间O(n+m)，不必把主串指针退回。不同next或前缀函数定义有不同下标约定，必须先写定义。

二维数组按行优先时，a[i][j]偏移为(i×列数+j)×元素大小。稀疏矩阵可按(行,列,值)三元组存非零项，另存尺寸与数量；适合零很多但索引元数据也有成本。

### 推导
定义前缀函数π[i]为模式0…i的最长相等真前缀/后缀长度，“真”表示不能用整个串。模式ABAB的π=[0,0,1,2]。若已匹配ABAB后失配，可保留长度2的AB，从较短候选继续，不重查主串前两位。

### 例题1
主串ABABC、模式ABC。朴素在0匹配AB后遇A≠C失败，起点1首字符B失败，起点2匹配成功。0起始返回2。

### 例题2
3×4按行数组，每项4字节，a[2][1]偏移(2×4+1)×4=36字节。矩阵[[0,5,0],[0,0,7]]只存(0,1,5)、(1,2,7)及2×3尺寸，转置时交换行列并按需要重新排序。

### 练习1
“AC”是“ABC”的子串吗？
提示：是否连续？
解析：不是子串，是子序列。模式匹配题若没说子序列，不能跳过B。

### 练习2
求AAAA的前缀函数π。
提示：每个前缀排除自身。
解析：[0,1,2,3]；最后最长真前后缀AAA长3。

### 练习3
所有矩阵都适合三元组存储吗？
提示：每项还保存两个坐标。
解析：不适合。稠密矩阵可能因坐标开销更大且访问更慢，应根据非零比例和操作模式选择。

### 回顾
表示法服务于操作；少存数据并不自动更快。

### 补充
先按图示和正文用纸笔追踪，再阅读以下伪代码。箭头←为赋值，“若”为条件，“当”为循环；不是可直接编译的C。

```伪代码
prefix(pattern):
  若模式空：返回空表
  pi[0] ← 0
  对 i=1 到 m−1：
    j ← pi[i−1]
    当 j>0 且 pattern[i]≠pattern[j]：j ← pi[j−1]
    若 pattern[i]=pattern[j]：j ← j+1
    pi[i] ← j
  返回 pi
空模式在查找中的结果须另定，本课约定匹配位置0。
```
