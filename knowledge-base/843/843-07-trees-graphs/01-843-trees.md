# 非线性结构、查找与排序

## 843-trees | 树、二叉树与遍历 | 树；二叉树；完全二叉树；遍历；二叉搜索树

### 目标
画树并按规定顺序遍历，理解搜索树的条件。

### 问题
文件夹有层级，为什么用一条链描述不自然？

### 讲解
树连接父子关系，无环；根没有父节点，叶子无子节点。二叉树每节点最多两个有区别的孩子，左和右不能随便交换。完全二叉树除最后层外满，最后层向左连续；不是所有二叉树都适合紧凑数组存储。遍历：先序根左右，中序左根右，后序左右根；层序使用队列。二叉搜索树BST要求每个节点左子树键较小、右子树较大，重复键策略须约定；中序结果有序。

### 推导
递归遍历先处理空树：直接返回；其余按所选顺序访问根和两个子树。搜索按比较选择一个分支，复杂度O(h)，h是树高；平衡时O(log n)，退化成链时O(n)。不是出现“树”就自动对数复杂度。

### 例题1
根B，左A，右D且D左C：先序B A D C，中序A B C D，后序A C D B，层序B A D C。每次先写规则再走图。

### 例题2
把1、2、3、4顺序插入普通BST会形成右链，查4需走4个节点。平衡树通过维护高度等信息避免这种退化，但本节不要求实现全部平衡操作。

### 练习1
知道中序序列就能唯一恢复二叉树吗？
提示：不同形状能有同一中序。
解析：不能；互异标签的中序配合先序或后序通常可重建，只有中序不够。

### 练习2
根2、左1、右3，写三种深度遍历。
提示：根访问的时机不同。
解析：先序2,1,3；中序1,2,3；后序1,3,2。

### 练习3
BST中序含重复值一定违反定义吗？
提示：先问重复键存放规则。
解析：不一定。有的实现合并计数，有的规定放某侧；题目必须统一规则，不能默认所有实现都禁止重复。

### 回顾
遍历是访问规则，搜索树是大小约束，两者别混淆。

### 补充
先按图示和正文用纸笔追踪，再阅读以下伪代码。箭头←为赋值，“若”为条件，“当”为循环；不是可直接编译的C。

```伪代码
preorder(node):
  若 node 为空：返回
  访问 node
  preorder(node.left)
  preorder(node.right)
将访问根移到两次递归之间是中序；移到之后是后序。
```
