## 进程和线程：状态、控制块、创建/撤销、切换、并发与并行（843-081）

- 章节：计算机软件技术 → A. 资源管理技术 ｜ 优先级：P0 ｜ 关键词：843、计算机基础、数据库、软件工程、AI、创新设计

### 学习目标

学完后，你能从资源管理和并发安全角度解释操作系统的机制。

### 问题与比喻

多个程序要同时使用 CPU、内存和设备，操作系统负责分配资源、隔离风险、协调顺序并提供统一接口。

> 类比：操作系统像一位总管：在有限的 CPU、内存和设备上，把很多任务安全地安排起来。

### 正式表达

操作系统是硬件资源的管理者和程序运行的服务者。“进程和线程：状态、控制块、创建/撤销、切换、并发与并行”要说明对象、状态变化、调度/同步规则和可能的代价。

### 掌握要点

- 进程和线程
- 状态
- 控制块
- 创建/撤销
- 切换
- 并发与并行

### 掌握路径

1. 先认对象：进程/线程、内存页、文件、设备或锁。
2. 画状态变化：谁等待、谁运行、谁持有资源，触发条件是什么。
3. 检查安全性和性能：死锁、饥饿、抖动、切换开销或隔离边界。

### 最小例题

**题**：死锁为什么需要同时满足多个必要条件？

**讲解**：
- 只有互斥不一定死锁。
- 还要存在持有资源同时等待新资源。
- 再加上资源不可剥夺和环形等待，系统才卡住。

**答案**：互斥、占有且等待、不可剥夺、循环等待同时存在，才会形成无法自行解除的资源等待环。

### 避坑

- 把并发和并行当成同一个概念。
- 只背死锁四条件，不会判断题目是否形成环。
- 分页、分段和虚拟内存的地址转换过程混淆。

### 考点用法

考试遇到“进程和线程：状态、控制块、创建/撤销、切换、并发与并行”时，先圈出题目条件，再调用对应的定义、步骤或判断标准。

### 自测

**问**：进程和线程的主要区别怎么说？

**答**：进程是资源分配和隔离的基本单位，线程是处理机调度和执行的基本单位；同进程线程共享地址空间等资源。

**解析**：一个更像房间，一个更像房间里的工作人员。

**题**：两个进程互相等待对方持有的锁，最直接说明了什么？

- P1 持有 A 等 B。
- P2 持有 B 等 A。

**答案**：存在循环等待；若同时满足其他三个条件，就会形成死锁。

### 最小例题

**题**：为什么 Cache 命中会比访问内存快？

**讲解**：
- CPU 先查 Cache。
- 命中就直接返回数据。
- 未命中才去更低层存储，并可能把数据装入 Cache。

**答案**：Cache 更靠近 CPU，容量小但速度快；命中表示所需数据已经在 Cache 中，省去访问更慢层级的等待。

> 类比：软件工程是在给复杂项目修建轨道：先理解问题，再设计、实现、验证和维护。

### 正式表达

“结构化/半结构化/非结构化数据；数据采集、清洗、存储、处理、分析和可视化”应从组成、工作流程和性能指标三层理解：它处理什么数据，经过哪些部件，受什么限制。

### 掌握要点

- 结构化/半结构化/非结构化数据
- 数据采集
- 清洗

- 处理
- 分析和可视化

### 掌握路径

1. 先定位层次：数制/编码、CPU、存储、I/O、总线或性能。
2. 画数据流：数据从哪里来，经过谁处理，结果写到哪里。
3. 用指标验证：容量、速度、命中率、CPI、带宽或溢出条件。

### 最小例题

**题**：为什么 Cache 命中会比访问内存快？

**讲解**：
- CPU 先查 Cache。
- 命中就直接返回数据。
- 未命中才去更低层存储，并可能把数据装入 Cache。

**答案**：Cache 更靠近 CPU，容量小但速度快；命中表示所需数据已经在 Cache 中，省去访问更慢层级的等待。

### 避坑

- 把容量、带宽、延迟和吞吐率混成一个概念。
- 补码、浮点数或编码只背名称，不会做表示和溢出判断。

$$

3. 最后检查秩、维数、可逆性、解的个数或正定条件是否匹配。

### 最小例题

**题**：方程组 x+y=3，x−y=1 的解是什么？

**讲解**：
- 两式相加得到 2x=4，所以 x=2。
- 代回 x+y=3，得到 y=1。
- 矩阵视角就是对增广矩阵做消元。

**答案**：x=2，y=1。

- 矩阵乘法把行列顺序写反。

- 所有结果都是 3，所以平均值为 3。
- X 与平均值没有偏离。
- 偏离平方的平均为 0。

**答案**：E(X)=3，Var(X)=0。

### 避坑

- 把方差当成标准差。
- 忘记 Var(aX+b)=a²Var(X)。
- 把不相关直接说成独立。

### 考点用法

考试遇到“神经网络和深度学习概述；训练、泛化、偏差/方差；计算机视觉和自然语言处理应用”时，先圈出题目条件，再调用对应的定义、步骤或判断标准。

### 自测

**问**：为什么独立一定不相关，但不相关不一定独立？

**答**：独立会使联合分布可分解，从而协方差为零；协方差为零只排除了线性相关，可能仍有非线性依赖。

**解析**：独立是更强的整体关系，不是单个数字条件。

### 最小例题

**题**：浏览器输入域名到看到网页，DNS 和 HTTP 分别做什么？

**讲解**：
- 先查通讯录得到服务器地址。
- 再建立合适的传输连接/发送请求。
- 服务器返回响应，浏览器解析展示。

**答案**：DNS 把域名解析为 IP；HTTP 按应用协议请求和传输网页资源。

### 避坑

- 把 IP 地址、MAC 地址和端口号混用。
- 把 TCP 的可靠性误认为 IP 层提供。
- 背七层模型但不能解释一次真实请求。
