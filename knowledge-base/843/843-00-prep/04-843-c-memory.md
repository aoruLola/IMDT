# 预备篇：读懂符号与程序

## 843-c-memory | 数组、指针与结构体怎样配合 | 数组；地址；指针；结构体；空指针

### 目标
区分位置和值，看懂链表节点所需的最小C语法。

### 问题
图书记录既要存编号又要找到下一本，为什么一个整数不够？

### 讲解
数组把同类型元素连续存放。地址是位置的标识；指针保存地址。C中&x取得x的地址，*p在p指向合法对象时读写该对象。NULL表示不指向有效对象，不能解引用。结构体把不同字段组合为记录：struct Node { int value; struct Node *next; }; next保存下一节点的地址。p->value读取指针p所指结构体的value字段。

指针不是它所指的值；复制指针会让两个指针访问同一对象。动态分配要检查失败，释放后不能继续使用该块内存。这里先通过箭头理解，链表章再动手操作。

### 推导
画两个层次：变量框中写地址，箭头指向对象框；改变p会换指向，改变*p会改对象值。数组访问a[i]须满足0≤i<n；先确认对象存在，再沿箭头访问。

### 例题1
x=3，p=&x，随后*p=8。因为p仍指向x，最后x=8。若只把p设为NULL，则x仍8，改变的是指针本身。

### 例题2
节点A=(4,指向B)，B=(7,NULL)。从A访问next得到B，再读value得7；B的next为NULL说明到尾端，不应再读NULL->value。

### 练习1
q=p后，修改*q是否可能改变*p？
提示：画两根箭头。
解析：如果它们仍指向同一个合法对象，会改变同一份值。复制地址没有复制对象。

### 练习2
a=[10,20,30]，i=1，a[i]=a[i-1]+5后数组是什么？
提示：C数组从0编号。
解析：[10,15,30]。只更新第二项，第一、三项不变。

### 练习3
释放节点后继续沿它的next访问安全吗？
提示：释放后对象还属于程序吗？
解析：不安全，属于释放后使用。应先保存需要的next，再释放当前节点；保存的next也必须指向仍存活的节点。

### 回顾
先看地址指向谁，再看读写的是地址还是对象。
