## A. 马克思主义哲学

- [ ] `P0` 哲学基本问题：物质和意识、思维和存在的关系；唯物主义与唯心主义；可知论与不可知论。
- [ ] `P0` 物质观：物质的客观实在性；运动与静止；时间与空间；物质运动的规律性。
- [ ] `P0` 意识观：意识的起源、本质、能动作用；主观能动性与客观规律性的关系。
- [ ] `P0` 世界的物质统一性；自然界与人类社会的物质性；人与自然的关系。
- [ ] `P0` 实践观：实践的本质、基本特征、基本形式；实践与认识的关系。
- [ ] `P0` 认识论：认识的本质、来源、发展动力、目的；感性认识与理性认识；认识运动的规律。
- [ ] `P0` 真理：真理的客观性、绝对性、相对性；真理与谬误；实践是检验真理的标准。
- [ ] `P0` 认识规律：从实践到认识、从认识到实践；认识运动的反复性和无限性。
- [ ] `P0` 唯物辩证法总特征：联系、发展；联系的客观性、普遍性、多样性和条件性；发展的实质。
- [ ] `P0` 三大规律：对立统一规律、量变质变规律、否定之否定规律。
- [ ] `P0` 基本范畴：现象与本质、内容与形式、原因与结果、必然与偶然、现实与可能。
- [ ] `P0` 矛盾：同一性与斗争性、普遍性与特殊性、主要矛盾与次要矛盾、矛盾主要方面与次要方面、具体问题具体分析。
- [ ] `P0` 唯物史观：社会存在与社会意识；社会意识相对独立性；生产力与生产关系；经济基础与上层建筑。
- [ ] `P0` 社会形态；社会基本矛盾；阶级、国家、革命；人民群众和个人在历史中的作用。

网课关键词：`马原哲学基本原理`、`物质意识实践认识`、`唯物辩证法三大规律`、`社会基本矛盾`。

### B. 马克思主义政治经济学

- [ ] `P0` 商品：商品二因素、劳动二重性、价值量、社会必要劳动时间、价值规律。
- [ ] `P0` 货币：货币的职能；价值尺度、流通手段、支付手段；货币流通规律。
- [ ] `P0` 资本：资本总公式及矛盾；劳动力商品；不变资本与可变资本；剩余价值。
- [ ] `P0` 剩余价值生产：绝对剩余价值、相对剩余价值、超额剩余价值；资本主义工资。
- [ ] `P0` 资本积累：资本主义再生产；资本有机构成；相对过剩人口；资本积累的一般规律。
- [ ] `P0` 资本循环与周转：货币资本、生产资本、商品资本；周转时间、周转速度、固定资本与流动资本。
- [ ] `P0` 社会总资本再生产和流通；社会总产品；两大部类；简单再生产与扩大再生产。
- [ ] `P0` 平均利润与生产价格；商业资本、借贷资本、银行资本；利息和地租。
- [ ] `P0` 垄断资本主义：垄断形成、垄断利润；国家垄断资本主义；经济全球化。
- [ ] `P0` 资本主义制度的历史地位、内在矛盾和被社会主义替代的历史必然性。

网课关键词：`政治经济学商品货币`、`剩余价值`、`资本积累`、`资本循环周转`、`垄断资本主义`。

#### C. 科学社会主义

- [ ] `P0` 社会主义从空想到科学的发展；科学社会主义的理论基础和基本原则。
- [ ] `P0` 社会主义代替资本主义的历史必然性；无产阶级解放和人的自由全面发展。
- [ ] `P0` 社会主义革命、建设和发展的一般规律；社会主义发展道路的多样性。
- [ ] `P1` 共产主义社会的基本特征；实现共产主义的长期性、艰巨性和阶段性。

### 2.3 习近平新时代中国特色社会主义思想概论（习思想）

- [ ] `P0` 新时代的历史方位、社会主要矛盾变化、党的中心任务和强国建设目标。

- [ ] `P0` 中国式现代化：人口规模巨大、全体人民共同富裕、物质文明和精神文明相协调、人与自然和谐共生、走和平发展道路。
- [ ] `P0` 以中国式现代化全面推进中华民族伟大复兴；高质量发展、新发展理念、新发展格局。
- [ ] `P0` 全面深化改革；社会主义市场经济；科技自立自强；教育、科技、人才一体推进。
- [ ] `P0` 全过程人民民主；全面依法治国；文化自信和社会主义文化强国。
- [ ] `P0` 保障和改善民生；共同富裕；生态文明建设；美丽中国。
- [ ] `P0` 总体国家安全观；国防和军队现代化；“一国两制”和祖国统一。
- [ ] `P0` 构建人类命运共同体；和平发展；全球发展倡议、全球安全倡议、全球文明倡议等相关表述。
- [ ] `P0` 全面从严治党；党的自我革命；党的领导、党的建设和中国式现代化的关系。
- [ ] `P1` 党的二十大、二十届历次全会及截至考试前的重要会议精神，以当年资料为准。

网课关键词：`习思想专题`、`中国式现代化`、`高质量发展新发展格局`、`全过程人民民主`、`生态文明美丽中国`、`全面从严治党`。
