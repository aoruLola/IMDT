# 算法与线性结构：让步骤可执行

## 843-lists | 顺序表与链表：搬元素还是改指针 | 线性表；顺序表；单链表；插入；删除

### 目标
逐步执行两种存储结构的插删，选择合适实现。

### 问题
队伍中间插一个人，数组和链表为什么付出的工作不同？

### 讲解
线性表是有序元素序列的逻辑结构；顺序表连续存储，按下标O(1)访问，中间插删需移动；链表通过指针连接，查第i个一般O(n)。已知前驱节点时，单链表插删可O(1)，但寻找位置的时间不能漏算。链表额外保存指针，缓存局部性通常不如数组。带头节点可统一首元素操作，头节点不必存业务数据。

### 推导
数组位置i插入v：检查容量→从尾向右搬移→a[i]←v→长度加1。链表在p后插入s：先s.next←p.next，再p.next←s，顺序反了会丢原后继。删除p后q：保存q←p.next→p.next←q.next→释放q。需检查q存在。

### 例题1
[2,5,8]在下标1插4：先8右移，再5右移，写4，得[2,4,5,8]。若从左往右移会覆盖未保存的数据。

### 例题2
A→B→C在A后插S：先S→B，再A→S，得到A→S→B→C。删除B须先找到其前驱S；只持有B地址时不能一般性地声称O(1)完成所有单链表删除情形。

### 练习1
链表按下标访问一定比数组快吗？
提示：能否直接算第i项地址？
解析：不能。数组通常O(1)，单链表需沿next走，最坏O(n)。

### 练习2
A→B→C删除B，写出修改的指针。
提示：先定位前驱A。
解析：q←A.next即B；A.next←q.next即C；释放q。A→C，不能先释放B再读B.next。

### 练习3
空表删除首元素要检查什么？
提示：首节点是否存在？
解析：检查头指针或头节点next不为空；不存在则返回失败/空结果，不能解引用NULL。

### 回顾
选择结构时，把“找到位置”和“修改位置”分开算。

### 补充
先按图示和正文用纸笔追踪，再阅读以下伪代码。箭头←为赋值，“若”为条件，“当”为循环；不是可直接编译的C。

```伪代码
insert_after(p,s):
  要求 p,s 有效且 s 不在链中
  s.next ← p.next
  p.next ← s
remove_after(p):
  q ← p.next
  若 q 为空：返回失败
  p.next ← q.next
  保存结果，再释放由本表拥有的 q
```
