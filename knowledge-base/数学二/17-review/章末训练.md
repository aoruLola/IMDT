# 综合复习：选择方法与检查答案 · 章末综合训练

## 原创综合训练

**题目**

分别验证：∫₀¹x ln x dx=-$\frac14$；A=[[2,1],[1,2]]正定。为每一结论写两种检查。

**提示**

一题查符号与分部，一题查主子式与特征值。

**解析**

积分分部为[$\frac{x^2\ln x}2$-$\frac{x^2}4$]₀¹=-$\frac14$，下端极限0；又x ln x≤0，答案非正且有限，作量级检查。矩阵顺序子式2、3均正；另一方法特征值3、1均正。两种验证分别检验计算与条件，而不只是重复抄结果。
