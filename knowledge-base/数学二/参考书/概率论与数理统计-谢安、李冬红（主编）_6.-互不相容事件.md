若事件 A 与 B 不能同时发生，即 AB =  $ \varnothing $，则称事件 A 与 B 互不相容（或 A 与 B 互斥）.

事件 A 与 B 互不相容表示 A 与 B 没有公共的样本点. 如图 1-1(e) 所示.

若事件  $ A_{1}, A_{2}, \cdots, A_{n} $（或  $ A_{1}, A_{2}, \cdots, A_{n}, \cdots $）中任意两个事件都互不相容，即  $ A_{i} A_{j} = \varnothing $ ( $ i \neq j $; i, j = 1, 2, ⋯, n 或 i, j = 1, 2, ⋯, n, ⋯ $)，则称事件  $ A_{1}, A_{2}, \cdots, A_{n} $（或  $ A_{1}, A_{2}, \cdots, A_{n}, \cdots $）两两互不相容.
