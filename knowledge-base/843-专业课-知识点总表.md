- [ ] `P1` 解释 AI、游戏、VR、空间计算等技术如何服务具体用户价值。

#### C. 思维力

- [ ] `P0` 用户中心设计、问题导向设计、设计思维的基本流程：同理—定义—构思—原型—测试。
- [ ] `P0` 发散与收敛；需求优先级；功能、成本、技术、伦理和可持续性的权衡。
- [ ] `P0` 互联网+思维：连接、平台、数据、协作、迭代、网络效应和服务化。
- [ ] `P0` 方案闭环：目标用户—核心问题—设计目标—功能机制—交互流程—验证指标。
- [ ] `P1` 用户中心设计不等于满足所有需求；需要识别核心需求、利益相关者和约束。
- [ ] `P1` 通用设计、无障碍设计、参与式设计、服务设计、社会创新设计。
- [ ] `P1` 可持续设计、循环设计、设计伦理、隐私保护、算法公平、计划性淘汰批判。
- [ ] `P1` 数字媒体、互动媒体、游戏机制、叙事、沉浸、反馈、奖励、留存和数值平衡。
- [ ] `P1` AI 交互、智能体、生成式内容、人与 AI 共创；能力边界、幻觉、控制权和责任。
- [ ] `P1` 产品评价：易用性、可用性、有效性、效率、满意度、留存、转化、完成率和社会影响。

网课关键词：`设计思维用户中心设计`、`通用设计参与式设计`、`服务设计社会创新`、`可持续设计设计伦理`、`游戏设计叙事互动媒体`、`AI交互智能体`。

#### D. 表现力

- [ ] `P0` 设计题读题：圈出目标用户、场景、问题、限制、交付形式和评价要求。
- [ ] `P0` 方案结构：问题/用户—目标—核心机制—功能—流程—反馈—验证—风险。
- [ ] `P0` 画面表达：标题、分区、层级、构图、线条、比例、箭头、编号、文字注释。
- [ ] `P0` 交互表达：页面/场景状态、入口、操作、反馈、异常、退出和循环路径。
- [ ] `P1` 低保真线框图、用户流程图、信息架构、故事板、场景图、角色/道具关系图。
- [ ] `P1` 基础视觉：点线面、形态、比例、节奏、对比、统一、色彩和字体可读性。

网课关键词：`设计快题手绘表达`、`交互产品草图`、`用户流程图线框图`、`故事板`、`设计题构图排版`。

### 5.9 创新设计概念与案例题词库

下列不是 2027 官方大纲逐字列出的名词表，而是依据参考书主题和历年真题整理的答题准备范围：

- [ ] `P0` 设计、艺术设计、功能、形式、审美、技术、材料、文化、社会价值。
- [ ] `P0` 用户中心设计、设计思维、参与式设计、通用设计、无障碍设计。
- [ ] `P0` 数字媒体、互动媒体、交互设计、界面、沉浸、虚拟现实、增强现实。
- [ ] `P0` 游戏、游戏机制、游戏叙事、互动叙事、奖励、成就、留存、数值平衡。
- [ ] `P0` 社会创新、服务设计、可持续设计、循环设计、设计伦理。
- [ ] `P1` 非物质设计、网站转化率、用户留存率、可用性、用户体验、产品价值。
- [ ] `P1` 人工智能、生成式 AI、智能体、新型交互、算法偏见、隐私和责任。
- [ ] `P1` 生态、教育、健康、低收入群体、老年人、残障用户、公共服务等社会议题案例。

#### 名词解释

1. 先给定义；2. 写核心特征；3. 说明与相近概念的区别；4. 给出一个数字媒体/游戏/AI/生态案例；5. 回到用户价值或社会价值。

#### 辨析题

1. 判断命题是否绝对；2. 拆出成立条件；3. 分析正面价值和边界；4. 结合案例；5. 给出有条件的结论。

#### 案例简答题

1. 用户与场景；2. 真实问题；3. 设计目标；4. 核心功能/机制；5. 技术如何服务设计；6. 验证指标；7. 风险、伦理和迭代。

#### 综合设计题

1. 先写题目和一句话方案；2. 画用户/场景；3. 画核心流程或界面状态；4. 标注关键交互和反馈；5. 说明创新点、技术实现和验证方式；6. 检查是否回应题目限制。

验收标准：每周至少完成 1 道 843 设计分析或手绘题；限时 60—90 分钟，保留草稿、成稿和复盘，不只收藏参考图。

### 6.1 看课顺序
