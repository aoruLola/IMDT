# 非线性结构、查找与排序

## 843-sorting | 排序过程、稳定性与取舍 | 插入；冒泡；选择；快排；归并；堆排；希尔；基数；稳定性

### 目标
手动走一轮排序，按输入特点比较算法。

### 问题
成绩相同的人要保留报名先后，选排序方法时要多看哪个指标？

### 讲解
稳定排序保持相同键元素原先的相对顺序。直接插入把当前元素插到已排好前缀；冒泡比较邻项并交换；简单选择每轮找最小换到前面。三者通常O(n²)，插入在近乎有序时可高效。快速排序按枢轴分区再递归，平均O(n log n)、最坏O(n²)；归并把有序段合并，O(n log n)、数组实现常用O(n)额外空间；堆排维护大根堆，每轮根换到末端再调整，O(n log n)。

希尔排序以递减间隔作插入，复杂度依间隔序列，通常不稳定。基数排序按位或字符分配，要求每趟稳定，适合可分解的键，时间常写O(d(n+r))，d为位数、r为基数。常见稳定实现：插入、冒泡、归并、基数；选择、快排、堆排、希尔一般不稳定。

### 推导
先写算法版本再追踪。插入若只移动严格大于当前键的项，可保留同键顺序；归并相等时先取左侧才稳定。快排最坏常来自极端不平衡分区，随机化降低遇到这种输入的风险，但不是取消最坏界。

### 例题1
[3,1,2]插入：初始已排[3]；把1前插得[1,3,2]；取2移3得[1,2,3]。归并则拆为[3]与[1,2]，排序后逐个比较首项合并。

### 例题2
带身份[2a,2b,1]简单选择首轮把1与2a交换，成[1,2b,2a]，相等2的顺序颠倒，证明不稳定。只看数字[1,2,2]会看不出这个问题。

### 练习1
排序正确就一定稳定吗？
提示：相同值背后还有身份。
解析：不一定。正确只要求键有序，稳定还要求同键原相对顺序保持。

### 练习2
[4,2,3,1]冒泡从左到右一趟，每次大于就交换，结果？
提示：大数逐步向右。
解析：4与2换→[2,4,3,1]，再换3→[2,3,4,1]，再换1→[2,3,1,4]。一趟只保证最大值就位。

### 练习3
用归并相等时先取右边，稳定性如何？
提示：跨两半的同键会谁先输出？
解析：可能失稳。左半原先靠前却后输出；相等时先左可保持稳定。

### 回顾
比较排序不仅看时间，还看稳定性、空间和输入特征。

### 补充
先按图示和正文用纸笔追踪，再阅读以下伪代码。箭头←为赋值，“若”为条件，“当”为循环；不是可直接编译的C。

```伪代码
insertion(a,n):
  对i=1到n−1：
    value ← a[i]；j ← i
    当j>0且a[j−1]>value：
      a[j] ← a[j−1]；j ← j−1
    a[j] ← value
严格大于才右移，可保持同键顺序。
```
