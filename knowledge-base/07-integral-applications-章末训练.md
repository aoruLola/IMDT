# 积分的应用 · 章末综合训练

## 原创综合训练

**题目**

区域0≤y≤x、0≤x≤2，求面积、绕x轴旋转体积，并求均匀薄片的形心。

**提示**

以竖条切片；形心是坐标的面积加权平均。

**解析**

A=∫₀²x dx=2；V=π∫₀²x²dx=$\frac{8\pi}3$。竖条面积x dx、中心高度$\frac x2$，所以横坐标=$\frac{\int_0^2x^2\,dx}{2}$=$\frac43$，纵坐标 $\bar y=\frac{\int_0^2\frac{x}{2}x\,dx}{2}=\frac23$。这与三角形三个顶点(0,0)、(2,0)、(2,2)的平均一致。
