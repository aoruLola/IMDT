## 4.1 高等数学：函数、极限与连续

- [ ] `P0` 函数：定义域、值域、复合函数、反函数、初等函数、分段函数、参数方程。
- [ ] `P0` 数列极限：定义、性质、夹逼准则、单调有界准则、子列和收敛。
- [ ] `P0` 函数极限：左右极限、无穷小与无穷大、等价无穷小、极限运算法则。
- [ ] `P0` 极限计算：因式分解、有理化、等价替换、泰勒展开基础、洛必达法则、夹逼。
- [ ] `P0` 连续：连续定义、间断点类型、闭区间连续函数性质、零点定理、介值定理。
- [ ] `P1` 渐近线与极限综合；参数变化、分段函数连续性和可导性。

网课关键词：`数学二函数极限连续`、`等价无穷小`、`洛必达`、`闭区间连续函数性质`。

### 4.2 一元函数微分学

- [ ] `P0` 导数定义、几何意义、物理意义；可导与连续的关系。
- [ ] `P0` 导数和微分的运算法则；基本初等函数导数；复合、反函数、隐函数、参数方程求导。
- [ ] `P0` 高阶导数；微分形式不变性；相关变化率。
- [ ] `P0` 罗尔定理、拉格朗日中值定理、柯西中值定理；定理条件和结论。
- [ ] `P0` 洛必达法则；未定式类型、使用条件和多次使用。
- [ ] `P0` 单调性、极值、最值；费马定理；闭区间最值。
- [ ] `P0` 凹凸性、拐点、渐近线、函数图像描绘。
- [ ] `P0` 导数综合：零点个数、方程根、参数讨论、不等式证明、最值应用。
- [ ] `P1` 曲率、弧微分等内容：按目标课程/真题要求选择性了解，通常不是数学二主线。

### 4.3 一元函数积分学

- [ ] `P0` 原函数与不定积分；基本积分公式；换元法、分部积分法。
- [ ] `P0` 有理函数、三角函数、简单根式函数积分。
- [ ] `P0` 定积分定义、性质、几何意义；可积性。
- [ ] `P0` 微积分基本定理；变上限积分；含参积分的求导。
- [ ] `P0` 定积分换元法、分部积分法、奇偶性、区间对称性。
- [ ] `P0` 反常积分的基本概念和收敛判断。
- [ ] `P0` 定积分应用：平面图形面积、旋转体体积、平均值、物理/几何应用。
- [ ] `P1` 积分不等式、积分估值、含参数积分和综合证明题。

网课关键词：`数学二不定积分`、`变上限积分`、`定积分计算技巧`、`定积分应用`。

### 4.4 常微分方程

- [ ] `P0` 微分方程基本概念：阶、解、通解、特解、初值条件。
- [ ] `P0` 可分离变量方程。
- [ ] `P0` 齐次型一阶方程。
- [ ] `P0` 一阶线性方程：通解公式、常数变易法。
- [ ] `P0` 可降阶高阶方程：缺少一个自变量或因变量的情形。
- [ ] `P0` 二阶常系数齐次线性方程：特征根、重根、共轭复根。
- [ ] `P0` 简单二阶常系数非齐次线性方程：待定系数法。
- [ ] `P0` 线性微分方程解的性质和结构；初值问题。
- [ ] `P1` 微分方程简单应用：增长衰减、几何/物理模型。

### 4.5 多元函数微分学

- [ ] `P0` 二元及多元函数：定义域、极限、连续。
- [ ] `P0` 偏导数、高阶偏导数、混合偏导数。
- [ ] `P0` 全微分、可微条件、连续/偏导/可微之间的关系。
- [ ] `P0` 复合函数求导、隐函数求导、方向导数和梯度的基础概念。
- [ ] `P0` 多元函数极值：无条件极值、条件极值、拉格朗日乘数法。
- [ ] `P0` 二元函数极值判别；最值应用。
- [ ] `P1` 多元微分综合：参数讨论、隐函数方程、几何和优化应用。

### 4.6 二重积分

- [ ] `P0` 二重积分定义、性质、几何意义。
- [ ] `P0` 直角坐标计算：矩形区域、一般区域、先二后一/先一后二。
- [ ] `P0` 极坐标变换：坐标关系、雅可比因子、区域边界和积分限。
- [ ] `P0` 二重积分应用：面积、体积、质量、质心等基础应用。
- [ ] `P0` 对称性、轮换次序、分块积分、区域画图。
- [ ] `P1` 二重积分综合和参数积分；三重积分、曲线曲面积分、格林/高斯/斯托克斯定理不列为数学二主线。

网课关键词：`数学二二重积分直角坐标`、`极坐标二重积分`、`交换积分次序`、`二重积分区域`。

### 4.7 线性代数

- [ ] `P0` 行列式：定义、性质、展开、余子式/代数余子式、克拉默法则。
- [ ] `P0` 矩阵：概念、运算、转置、逆矩阵、伴随矩阵、初等变换。

- [ ] `P0` 线性方程组：齐次/非齐次；高斯消元；解的判定；基础解系和通解。
- [ ] `P0` 向量组：线性相关/无关、极大无关组、秩、向量组等价。
- [ ] `P0` 向量空间基础：基、维数、坐标；线性表示。
- [ ] `P0` 特征值与特征向量：定义、特征方程、性质、求法。

- [ ] `P1` 线性代数证明题：秩、可逆、解空间、特征值和正定性综合证明。

网课关键词：`数学二线性代数行列式矩阵`、`线性方程组高斯消元`、`特征值特征向量`、`二次型正定`。
