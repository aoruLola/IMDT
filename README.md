# 数学二与843教学网站

面向 2027 全国统考数学二（302）备考的静态课程网站。保留电子报设计：纸色背景、少量绿色、三档正文层级、小章节阅读。阅读器已迁入 Vue 3 单文件组件，由 Vite 编译为静态资源；正文和公式仍预渲染。部署方式见 [Vue 构建说明](VUE-BUILD.md)。

## 843 课程已并列加入

843入口：<http://127.0.0.1:4174/843/>。17章72节，藏蓝主题；含144道示范、216道主线练习、17组章末训练、六个案例、两套150分原创模拟卷与手绘模板。两科共用阅读器，所有学习记录按科目隔离。详细构建、内容源与核验说明见 [843说明](content/843/README.md)。

## 学习工作台与专注课件

- 学习工作台：<http://127.0.0.1:4174/study.html>。今日任务、阶段计划与暂定考试日倒计时、完成进度、知识点索引绑定、成绩记录、错题回炉、JSON 导入导出。工作台只做计划与记录，正文仍在讲义页。
- 每个小节提供「专注课件」：PPT 式 7 页（问题→直觉→正式→跟着做→示范→自己回答→回顾），支持左右键翻页、答案延迟揭示、进度与自评持久化。默认仍是电子报长文。
- 知识点映射：`point-id → course-id → lesson-section-id`。政治/英语一标为「索引/待补正文」；未绑定显示「尚未绑定正文」。融合覆盖见 [FUSION-COVERAGE.md](FUSION-COVERAGE.md)。
- 存储隔离：工作台 `workbench-v1`，PPT 焦点 `math2-focus-v1` / `843-focus-v1`。备份 v2 包含两科已读、计时、成就、小标题及课件记录，兼容旧 v1 备份。恢复在计时锁内合并：同名记录保留当前值，已读取并集，同日时长取较大值，计时暂停；重复导入不会重复累计。旧备份未包含的小标题和课件记录无法凭空恢复。
- 今日任务按本地日期保存，优先到期错题，再交替安排两科。小节估算30分钟、错题15分钟，受正常／最低时长约束；每周学习日从周一开始。任务勾选可撤销，不自动标记讲义已读；已完成任务不在次日重复安排。
- 课件例题先显示题目，展开后显示原文完整示范；没有独立提示的例题只显示解析按钮。`worked-prompts.cjs` 补充原文未单独写出的问题，不复制答案。三个图示控制器支持动态初始化、停止和清理。
- `check-fusion-behavior.cjs` 已纳入 `npm run check`，覆盖备份往返、合并、旧版迁移、错误文件与写入失败回滚、按日任务、两科课件揭示和恢复、图示控制及退出清理。

`npm run build`一次构建并检查两科。以下原有内容清单专指数学二。

## 运行

需要 Node.js 22.12 或更新版本。

```powershell
# 首次安装构建依赖（当前工作区已经安装）
npm run setup

# 一次构建原版素材、独立样张、全课程与覆盖报告，并检查链接
npm run build

# 本机预览；保持这个进程运行
npm run preview
```

打开 <http://127.0.0.1:4174/>。服务器仅绑定本机回环地址，不对外发布。可通过环境变量 `PORT` 指定其他端口。`npm run package` 生成保留目录结构的 Nginx 部署包，网站文件位于包内 `html/`。

## 内容与功能

- 18 个章节单元、72 个教学小节：预备篇、高等数学、线性代数和综合复习。
- 主线每节有具体问题、解释、推导、两道例题、三类原创练习、独立提示/解析和回顾。
- 144 道主线例题、216 道主线练习、18 组原创章末训练；另有原版迁移的补充讲解和练习。
- 2024、2025 数学二共 17 道不同真题的要点与独立解析；跨章节题明确链接前置知识，有些题在相关章节重复引用，不重复计作不同真题。
- 函数、极限与连续保留原图，新增基本函数、切线、凹凸、积分切片、区域换序、矩阵变换、消元、特征向量、二次型交互 SVG。
- 首页、总目录、标题/关键词检索、章节独立页面、分节/本章全文、前置知识往返、本地阅读位置与可撤销已读标记。
- KaTeX 在构建时渲染，CSS、字体和图形都在本地；阅读不需要访问 CDN。
- 页面右下角提供持久化学习计时器，以及“学习记录与成就”面板：今日/累计时长、学习天数、10项成就及达成进度。
- 正文各小标题右侧提供图标：圆圈标记完成并折叠，箭头单独展开/收起。完成后圆圈显示勾选，可再次点击撤销；鼠标悬停有说明。状态按稳定内容标识保存在 `math2-reading-part-v1:*`，刷新、跨章和多个标签页同步；不自动标记整节已读。直达例题/练习的链接临时展开目标，打印时展开全部正文。

### 学习计时与成就

点击“开始计时”后，当前获得焦点且可见的课程标签页按秒累计，切换章节与刷新可接续。离开标签页、关闭页面或休眠期间不补算时长；返回后继续，点击“暂停计时”则保持暂停。意外中断时最多丢失最后一次保存之后约1秒的记录，页面接续等待上一个标签的计时权释放时可能有最多5秒间隔。

`math2-study-v1` 保存按本地日期划分的学习毫秒数、计时开关及成就达成日期。通过 Web Locks 串行保存及可过期的计时所有权防止多个标签重复累计。需要支持 Web Locks 的浏览器（本机预览可用）；存储不可用时明确提示并停用计时，不影响课程阅读。

成就包含累计1分钟、25分钟、2小时、10小时；3/7个学习日；阅读1节、10节、完整1章与全课程。每天累计满1分钟才计为学习日，不要求连续。阅读成就依据现有已读记录，撤销已读会重新计算，不代表掌握程度。记录仅在当前浏览器及同一网站地址下保存，清除网站数据会删除记录。

### 编写小节

Markdown 使用明确的受限结构：`## stable-id | 标题 | 考点；考点`，其下依次写 `### 目标 / 问题 / 讲解 / 推导 / 例题1 / 例题2 / 练习1 / 练习2 / 练习3 / 回顾`。练习中分别写 `提示：` 与 `解析：`。行内数学用 `$...$`，独立公式用 `$$...$$`，由 KaTeX 严格渲染，错误会使构建失败。常见 `[[a,b],[c,d]]` 矩阵简写会转换为正规矩阵排版。

新增小节后修改 `course.json`，确保稳定标识不改名、顺序合理、前置知识无环。`seed-manifest.cjs` 是目录初建工具，重新运行会重建清单，日常改稿无需运行。构建会检查清单与源稿是否一致。

### 旧地址与进度

根地址的 `#function`、`#domain`、`#limit` 等和 `函数极限连续-样张.html#…` 有显式迁移映射。迁移前完整页面保存在 `site/legacy/函数极限连续-样张.html`。独立样张仍为 `专注阅读-样张.html`，未与正式课程混合。

旧存储键 `math-lecture-chapters-v1` 首次映射到新键 `math2-course-v1`；保留旧键，不破坏原版记录。新记录按稳定小节标识保存，已读可撤销，不推断掌握程度。存储不可用时可正常阅读但不记忆进度。
