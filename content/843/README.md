## 内容

- 17章、72个教学小节；每节2道示范和3类带独立提示、解析的练习：144道示范、216道主线练习。
- 17组章末原创综合训练、6个贯穿案例及6道案例实践、两套各150分的原创模拟卷（共18题）。合计257个练习卡，不把示范或重复图示算成新增考点。

- 大纲覆盖分两级：21条官方要求与72个教学小节；`site/coverage.json`列正文、示范、练习、前置、来源和范围类型。
- 藏蓝主题 `#365674` / `#EDF1F5`，沿用纸色、电子报布局、三档字号。无新增前端框架。

## 构建与预览

在项目根目录运行：

```powershell
npm run setup    # 仅首次，安装现有构建依赖
npm run build    # 一次构建并检查数学二、843和原有独立样张
npm run preview  # 127.0.0.1:4173；已启动时不再重复运行
```

仅需Node.js 20或更新。静态页面无需访问CDN；本地服务不对外发布。源码与`site/`生成目录分离，生成目录已忽略于Git。

## 核验

`npm run check`执行两科结构检查、数学二原有11项计时检查，以及实际共享脚本的跨科隔离测试。

```powershell
# 标准库即可；可把python替换为本机Python的完整路径
python content/843/tooling/verify.py
# 编译器可用GCC/Clang或本次验证使用的官方TinyCC便携版
tcc -std=c11 -Wall -o algorithms.exe content/843/examples/algorithms.c
./algorithms.exe
```

本次TinyCC位于`tooling/.compiler/`，仅作校验，不是网站运行依赖，不复制进站点。计算报告为`NUMERIC-QA.json`，结构报告为`STRUCTURAL-QA.json`，隔离报告为`ISOLATION-QA.json`，人工教学与桌面检查记录见`QA.md`。
